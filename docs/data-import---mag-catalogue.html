2 Data Import - MAG Catalogue

2.1 Overview

WARNING: This is the MAG catalogue from short-read assemblies and not hybrid assemblies with PacBio.

This chapter prepares the Metagenome-Assembled Genome (MAG) catalogue for downstream analyses. All data processing steps are shown for transparency, but code chunks are set to eval=FALSE so they do not execute during bookdown compilation. The processed data is saved to .Rdata files which are then loaded in subsequent plotting chapters.

2.2 Genome (MAGs) Catalogue

Relevant metadata of genomes are fetched and merged into one genome metadata object for downstream analyses. This includes taxonomic classification, quality metrics, phylogenetic trees, and functional annotations.

2.2.1 Dereplicated Genomes

Bins were initially dereplicated at 99%, and annotations generated for all resulting MAGs. A second dereplication was performed at 95% to yield species-representative genomes. This analysis is performed on that subset.

Note: The drep.0.95.fa file must be processed first using terminal commands (shown in comments above) to extract unique genome names.

# This file is generated from the drep.0.95.fa file using terminal commands
# Note: warning=FALSE suppresses vroom parsing warnings (e.g., inconsistent column types)
selected_genomes <- read_tsv("data/MAG_catalogue/unique_genome_names.tsv", col_names = "genome") 

# Report number of species-representative genomes

2.2.2 Genome (MAGs) Taxonomy

This section processes the raw taxonomy table generated by GTDBtk and simplifies it for downstream analyses. Taxonomic classifications are parsed, cleaned, and formatted consistently.

# Load and process GTDBtk taxonomy summary file
# This contains taxonomic classifications for all MAGs at species level dereplication
# Note: Some rows have "N/A" in numeric columns (msa_percent, translation_table), 
# which causes parsing warnings. We suppress these and handle them properly.
genome_taxonomy <- read_tsv(
  "data/MAG_catalogue/gtdbtk.summary.tsv", 
  show_col_types = FALSE,
  na = c("", "N/A", "NA")  # Treat "N/A" as missing values
) %>%
  # Rename first column to standardize naming
  rename(genome = user_genome) %>% 
  # Remove .fa extension from genome names for consistency
  mutate(genome = str_replace_all(genome, "\\.fa", "")) %>% 
  # Filter to only include species-representative genomes (95% dereplication)
  filter(genome %in% selected_genomes$genome) %>%
  # Parse the classification string into separate taxonomic level columns
  # GTDBtk format: d__Domain;p__Phylum;c__Class;o__Order;f__Family;g__Genus;s__Species
  separate(classification, c("domain", "phylum", "class", "order", "family", 
                             "genus", "species"), sep = ";") %>% 
  # Remove GTDBtk prefix letters (d__, p__, etc.) from each taxonomic level
  mutate(across(domain:species, ~ str_sub(., 4))) %>% 
  # Select relevant taxonomic columns for downstream use
  select(genome, domain, phylum, class, order, family, genus, species) %>%
  # Handle missing or unclassified species names
  mutate(
    species = if_else(
      is.na(species) | species == "",
      paste0("unclassified_", genus),  # Use genus name if species missing
      species
    )
  ) %>%
  # Handle cases where both species and genus are unclassified
  mutate(
    species = if_else(
      is.na(species) | species == "unclassified_",
      paste0("unclassified_", family),  # Use family name if both missing
      species
    )
  ) %>%
  # Handle missing genus names
  mutate(
    genus = if_else(
      is.na(genus) | genus == "",
      paste0("unclassified_", family),
      genus
    )
  ) %>%
  # Handle duplicate species names by adding suffixes (_sp1, _sp2, etc.)
  group_by(species) %>%
  mutate(
    species = if (n() > 1) paste0(species, "_sp", row_number()) else species
  ) %>%
  ungroup()

# Rename Bacillota_I to Bacillota for consistency with other MAG catalogues
genome_taxonomy <- genome_taxonomy %>%
  mutate(phylum = case_when(
    phylum == "Bacillota_I" ~ "Bacillota",
    TRUE ~ phylum  # Keep all other phylum values as-is
  ))

2.2.3 Genome (MAGs) Quality

Quality properties of the genomes are assessed using CheckM2, which provides completeness, contamination, and other quality metrics for each MAG.

# Load CheckM2 quality report
# This contains completeness, contamination, genome size, and other quality metrics
# Note: warning=FALSE suppresses vroom parsing warnings (e.g., inconsistent column types)
genome_quality <- read_tsv("data/MAG_catalogue/checkm2.quality_report.tsv", show_col_types = FALSE) %>%
  # Rename first column (genome name column)
  rename(genome = 1) %>% 
  # Remove .fa extension from genome names for consistency
  mutate(genome = str_replace_all(genome, "\\.fa", "")) %>%
  # Filter to only include species-representative genomes (95% dereplication)
  filter(genome %in% selected_genomes$genome) %>%   
  # Select and rename relevant quality metric columns
  select(genome, Completeness, Contamination, Coding_Density, Genome_Size, Contig_N50) %>% 
  rename(completeness = Completeness, 
         contamination = Contamination, 
         coding_density = Coding_Density, 
         length = Genome_Size,
         N50_length = Contig_N50) %>%
  # Calculate circularity indicator: N50/length ratio
  # If N50 >= length, the genome is likely circularized
  mutate(circularity = N50_length/length) %>%
  mutate(circularity = ifelse(circularity >= 1, "1", "0")) %>%
  # For circularized genomes, assume 100% completeness and 0% contamination
  mutate(completeness = ifelse(circularity == "1", 100, completeness),
         contamination = ifelse(circularity == "1", 0, contamination)) %>%   
  # Calculate length ratio relative to median bacterial genome length
  # This helps identify unusually large or small genomes
  mutate(length_ratio = length/median(length, na.rm = TRUE))

# Report number of circularized genomes
cat("Number of circularized genomes:", sum(genome_quality$circularity == "1"), "\n")

2.2.4 Genome (MAGs) Phylogenetic Tree

This section loads and processes the phylogenetic tree generated by GTDBtk. The tree is pruned to include only the species-representative genomes used in this analysis. Note that the archaeal tree is only generated if archaea are detected among the genomes.

# Load GTDBtk phylogenetic tree (bacterial backbone tree)
genome_tree <- read.tree("data/MAG_catalogue/gtdbtk.backbone.bac120.classify.tree")

# Remove single quotes from tip labels (genome names) for consistency
genome_tree$tip.label <- str_replace_all(genome_tree$tip.label, "'", "") 

# Prune tree to keep only tips corresponding to selected genomes (95% dereplication)
genome_tree <- keep.tip(genome_tree, tip = selected_genomes$genome)

Note: If there are unmatched tip labels between the tree and selected genomes, this indicates some genome names don’t match between the tree file and the dereplication list. This may need manual checking.

2.2.5.1 Factoring of taxonomic levels

phylum_metadata <- genome_metadata %>%
  group_by(phylum) %>%  
  summarize(
    # Count the microsamples
    `number_of_genera` = n_distinct(genus),  
    # Collect unique values separated by commas
    genus = paste(unique(genus), collapse = ", "),
    phylum = paste(unique(phylum), collapse = ", "),
    .groups = "drop") %>%
  select(phylum, number_of_genera, genus) %>%
  # Preserve original order
  arrange(match(phylum, unique(genome_metadata$phylum)))  


order_metadata <- genome_metadata %>%
  group_by(order) %>%  
  summarize(
    # Count the microsamples
    `number_of_genera` = n_distinct(genus),  
    # Collect unique values separated by commas
    genus = paste(unique(genus), collapse = ", "),
    phylum = paste(unique(phylum), collapse = ", "),
    class = paste(unique(class), collapse = ", "),
    # Ensure the dataframe is ungrouped
    .groups = "drop") %>%
  select(phylum, class, order, number_of_genera, genus) %>%
  # Preserve original order
  arrange(match(order, unique(genome_metadata$order)))  

phylum_level_vector <- as.character(unique(phylum_metadata$phylum))
order_level_vector <- as.character(unique(order_metadata$order))

  • read_counts: Number of reads mapped to each genome in each sample. Note this is the unfiltered and unnormalised raw community composition table.
  • genome_counts: Number of genomes quantified in each sample, calculated through filtering and normalising read_counts. This is the community composition table to be used in downstream analyses unless otherwise stated.
